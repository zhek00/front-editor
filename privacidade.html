Política de Privacidade

Última atualização: 24 de setembro de 2026

O TipLabs é um painel de uso pessoal que controla a "fábrica de vídeos": um sistema que roda no computador do próprio usuário e gera vídeos narrados automaticamente. Este documento explica que dado é acessado, pra que serve e onde ele fica guardado.

O que é acessado na sua conta do Google/YouTube

Quando você conecta uma conta do YouTube ao TipLabs, o sistema pede permissão pra:

  • Ler informações básicas do seu canal (nome e foto), só pra mostrar qual conta está conectada.
  • Enviar vídeos ao seu canal e alterar a visibilidade deles (de Privado pra Público), quando você usa a publicação ou o agendamento.

O TipLabs nunca lê, apaga ou publica nada na sua conta por conta própria — toda publicação parte de uma ação explícita sua, feita na tela "Publicar no YouTube".

Onde os dados ficam guardados

Este é um sistema de um usuário só, sem servidor compartilhado nem banco de dados de terceiros. Tudo fica gravado localmente, no computador que roda a fábrica:

  • O token de acesso à sua conta do Google fica num arquivo local (youtube_conta.json), nunca é enviado a nenhum servidor além dos próprios servidores do Google.
  • Os vídeos, roteiros e metadados de cada projeto ficam em pastas locais, na máquina do usuário.

Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Outros dados públicos usados

A ferramenta "Procurar Nichos" consulta a API pública do YouTube (visualizações, inscritos, quantidade de vídeos de canais) só pra ajudar a encontrar temas de vídeo — não envolve login nem dado pessoal de ninguém, só estatísticas públicas dos próprios vídeos do YouTube.

Como revogar o acesso

Você pode desconectar a conta a qualquer momento pelo próprio painel (botão "Desconectar" na tela Publicar no YouTube) ou diretamente em myaccount.google.com/permissions.

Este é um projeto pessoal, não uma empresa nem um produto comercial com usuários cadastrados. Se você recebeu acesso a esta ferramenta de outra pessoa, essas mesmas regras valem pra sua conta também.
